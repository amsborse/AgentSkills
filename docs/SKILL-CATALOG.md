# Skill catalog

Ask in plain words; the agent picks the skill from its description. To see which skill a
request would hit: `node scripts/route.mjs "<request>"`. Machine-readable form:
`registry/skills.json` (generated by `node scripts/build-registry.mjs`).

Risk: **low** reads only, **medium** edits code in the repository, **high** acts outside the
repository or unattended.

| Skill | Ask for example | Builds on | Risk | Extra procedures |
| --- | --- | --- | --- | --- |

| `build-animation` | "Animate this hero", "match this reference image" | verify, revamp-ui, coordinate-agents | low | `workflows/cinematic-plate/`, `workflows/chapter-rail.md`, `workflows/heavy-hero-performance.md`, style add-ons in `styles/` |

call them by path; they are installed under the same names as before.

`unslop`) are mapped in `docs/MIGRATION.md`.
