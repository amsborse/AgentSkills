# Style add-ons

The skills (`revamp-ui`, `build-animation`) carry the general method: tokens first, a single
signature living visual, calm continuous motion, and verification with real screenshots. A style
add-on attaches a visual language to that method. It sets the material, how light behaves, the
motion character, and the anti-patterns that are specific to that look.

| Add-on | Use when | File |
| --- | --- | --- |
| Cinematic | photographic or painted scenes, atmosphere, depth, editorial storytelling | `cinematic.md` |
| Claymorphism | soft, tactile, playful-premium products; puffy matte surfaces | `claymorphism.md` |
| Glassmorphism | layered panels floating over a rich living background | `glassmorphism.md` |

## How to attach one

- **Pick it** from the user's words ("clay", "glass", "cinematic"), from the project's existing
  design system, or by asking once with numbered options. Record the choice in the project's
  ledger or `AGENTS.md`, so later agents keep using it.
- **Read the add-on before writing tokens.** Its rules sit on top of the UI taste section of the
  working agreements, and those still win. That means one accent, sharp readable text, a light
  mode that is designed rather than inverted, and calm motion.
- **Combine at most two.** One is the base and the other is an accent. For example, glass panels
  over a cinematic plate, or clay objects with a glass navigation bar. The base owns the tokens.
- **Keep the shared feel, whatever the style:**
  - Slow Lenis scroll.
  - The chapter dot rail on long pages (`skills/build-animation/workflows/chapter-rail.md`).
  - A single signature living visual, blended into the page.
  - Elements that travel to their new place.
  - Still-first heavy visuals (`skills/build-animation/workflows/heavy-hero-performance.md`).
  - Reduced motion that reacts mid-visit.

Each add-on has the same sections:

- Material and tokens
- Signature visual
- Motion character
- Performance
- Accessibility
- Anti-patterns
- Verify

A new add-on, such as neumorphism or brutalist, copies that shape and gets a row in the table
above.
